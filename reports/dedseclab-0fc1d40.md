# QuacksOnWelfare/DedSecLab — DO NOT USE
Commit `0fc1d40e683fef00349d3dd3cf6b753280f2c00b` · audited 2026-11-10 · Windows PyQt6 "cyber lab" client (`DedSecLabAPP_Beta/`) plus a self-hosted Linux server stack (`opt/secure-scripts/`: OpenVPN bridge, FastAPI-style lab API, SSH ForceCommand menus, owner/root panel and a folder of network tools).

**Bottom line:** No malware aimed at *you* was found. There is no call-home to the author, all server addresses are placeholders, and there is no obfuscation, downloaded-and-run code or hidden instructions. But a large part of the package targets **other people**. One feature crashes other people's Xbox Live party chats. "Pullers" collect the IP addresses of the people a VPN user plays or calls with (GTA/FiveM lobbies, WhatsApp/Facebook calls, Discord voice and more). A "surveillance" monitor tracks chosen IPs and sends Discord alerts. There is also a game "lag switch" and website recon. The README calls the project "defensive / authorised lab" work, but these features have no defensive use, so the framing contradicts the code. Also, the server installer lets the lab user become root. It does not run on macOS anyway (Windows client, Ubuntu/Debian server). **The VM run did not exercise any of it**, so this verdict rests on code review.

## What it can touch
- **Client network:** only the lab server URL you configure (CA-pinned). It also calls public IP/geo services (ipify, ifconfig.me, icanhazip, ip-api.com, partly over plain HTTP), Cloudflare speed test, httpbin, `profile.xboxlive.com` / `party.xboxlive.com` with your Xbox token, and `swupdate.openvpn.org` (OpenVPN MSI, Authenticode-checked).
- **Client files:** `%APPDATA%\DedSecLab\` (config, DPAPI/Credential Manager secrets, HMAC'd device fingerprint) and a plaintext `xbox_token.json`. It writes update zips to `~/Downloads`. The updater it unpacks is marked Hidden+System.
- **Client OS:** reads global key state while you record macros (local profiles only), lists local TCP connections and can kill processes. It runs the OpenVPN installer and OpenVPN with admin rights (`runas`), and launches Fiddler and the Xbox app.
- **Server:** apt-installs scanners and sniffers (nmap, nikto, tcpdump, tshark, scapy). It creates `dedsecuser`, adds it to the `sudo` group, and writes `/etc/sudoers.d/dedsec-lab`. It enables SSH and IP forwarding, adds iptables rules, and sniffs every VPN user's traffic on the owner panel.
- **Server network:** Discord webhooks (your own, placeholders in the repo), ip-api (pro and free), ipwho.is, ipinfo.io, Shodan (proxied), FiveM/CFX server lists, hackertarget, SEO/Alexa APIs (grim.php), and blocklists from `raw.githubusercontent.com`.
- **Persistence:** none on the client beyond its own app folder. The server adds a user, sudo rules and enabled services, all by design.

## Runtime behaviour (VM, decoy credentials, network blocked)
- **Scenario:** the auto-generated scenario was used. It detected "nothing executable" (no SKILL.md, plugin or package manifest at the repo root), so it only planted `~/.claude/settings.json` and `~/.claude.json` and printed them back.
- **Install:** 4 execs (`bash`, `env`, `mkdir`), no hosts, no DNS, no decoy reads.
- **Run:** 4 execs (`bash`, `env`, `cat`), no hosts, no DNS, no decoy reads, no persistence, no leftover processes. The only new files were the two configs the scenario planted.
- **None of DedSecLab's code ran.** These results say nothing about the client or server.

## How to use it safely
1. **Don't install or run it**, on the Mac or anywhere else, for the features above. If you want an OpenVPN + FastAPI lab, start from a project whose features don't target other people.
2. If you must study it, read the source only, or run the client in a disposable Windows VM with a throwaway Microsoft account and no real lab server. Never paste your real Xbox Live token into it.
3. Never run `opt/secure-scripts/dedsec-labNEW/install.sh` on a server you care about: it turns every lab account into root. Never connect to someone else's DedSecLab VPN or server, because its operator controls your updates and can see your traffic.
4. Don't use the committed ip-api key: it belongs to someone else.
